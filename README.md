## 깃허브 페이지 업로드 방법

### 1️⃣ 저장소 생성 (이미 생성되었다면 생략)
1. GitHub에 로그인
2. 새 저장소(Repository) 생성
3. 저장소 이름: `class-homepage`
4. Public으로 설정

### 2️⃣ 파일 업로드 방법

#### 방법 A: GitHub 웹사이트에서 직접 업로드
1. `https://github.com/nnabe715-lgtm/class-homepage` 접속
2. `Add file` → `Upload files` 클릭
3. `index.html` 파일을 드래그 앤 드롭
4. `Commit changes` 클릭

#### 방법 B: Git 명령어 사용 (터미널)
```bash
# 저장소 클론
git clone https://github.com/nnabe715-lgtm/class-homepage.git
cd class-homepage

# index.html 파일을 이 폴더에 복사

# Git에 추가 및 커밋
git add index.html
git commit -m "Add class homepage"
git push origin main
```

### 3️⃣ GitHub Pages 활성화
1. 저장소 설정(Settings) 이동
2. 왼쪽 메뉴에서 `Pages` 클릭
3. Source를 `main` 브랜치로 설정
4. Save 클릭

### 4️⃣ 사이트 접속
약 1-2분 후 다음 주소로 접속 가능:
**https://nnabe715-lgtm.github.io/class-homepage/**
